CurioFood

Herramienta privada para administrar canales de YouTube · Private channel management tool

Esta herramienta la usa únicamente su propietario para administrar sus propios canales de YouTube (por ejemplo, CurioFood y BAJO LA ETIQUETA, entre otros). Sirve para subir sus videos con título, descripción, miniatura y subtítulos, y para consultar las estadísticas de esos canales, mediante la API de datos de YouTube y la API de YouTube Analytics.

No es una app pública: no la usan otras personas y no pide acceso a cuentas ajenas.

This tool is used only by its owner to manage their own YouTube channels (for example CurioFood and BAJO LA ETIQUETA, among others): uploading their own videos and reading their own channel statistics through the YouTube Data API and the YouTube Analytics API.
